# Non-Counter Data Processing Application

## Setup

Dependencies are managed using [`uv`](https://lithic.tech/uv).\
They are listed in `pyproject.toml`.

The backend is **FastAPI** server, which can be launched using ```uv run fastapi dev```.\
The backend expects `.env` file with environment variables (**OPENAI_API_KEY**, **BRAIN_TOKEN**, **GITLAB_PROJECT_ID**, **GITLAB_API_TOKEN**).
The GITLAB_API_TOKEN must have access to the given Gitlab Project with r+w api scope.
This will start the server on `127.0.0.1:8000`.

The autogenerated FastAPI docs are on `127.0.0.1:8000/docs`.

### Structure
The entrypoint to the backend is `main.py`.
The most important base classes and runtime are located in `base.py`.
The specialized agents and data states can be found in `models.py` and `workers.py`.

### Prompts
The prompt templates are written using [`Jinja`](https://jinja.palletsprojects.com/en/stable/) templating.\
They are located in the `prompts/` directory and `prompts.py` is responsible for rendering the templates into final prompt strings.

## Frontend
Dependencies are managed using [`npm`](https://www.npmjs.com/).\
To install dependencies, run: `npm install`.

Frontend is wrriten in **Vue**, using Primevue extension. To launch the app on localhost, use `npm run dev`.
Frontend has its own .env file with **VITE_API_BASE_URL** variable.

## FlowData

**ParsedData**
- `columns`: list of column definitions (field, header)
- `rows`: list of parsed data rows

**DataDescriptionData**
- `begin_month_year`: start month/year (string)
- `end_month_year`: end month/year (string)
- `english`: boolean indicating if data is in English
- `title_report`: boolean indicating if report includes titles
- `item_report`: boolean indicating if report includes items
- `granularity`: enum (monthly, daily, other)
- `title_identifiers`: list of title identifier types
- `metrics`: list of MetricMapping (data_metric, brain_metric, interest_group)
- `dimensions`: list of DimensionMapping (data_dimension, brain_dimension)
- `organization`: optional organization name

**TranslationData**
- `metrics_translations`: list of metric translation strings
- `dimensions_translations`: list of dimension translation strings

**FileData**
- `path`: file path
- `format`: enum (CSV, XLSX, XLS)
- `file_name`: filename
- `sheets`: list of Sheet objects (name, contents)

**UserInfoData**
- `user_comment`: optional user comment/notes
- `gitlab_issue`: optional GitLab issue number
- `source`: optional source information

**PlatformData**
- `name`: platform full name
- `short_name`: platform short name
- `provider`: provider name
- `url`: platform URL
- `pk`: platform ID in Brain (optional)
- `exists`: boolean indicating if platform exists in Brain

**MetricsDimensionsData**
- `metrics`: list of MetricMapping (data_metric, brain_metric, interest_group)
- `dimensions`: list of DimensionMapping (data_dimension, brain_dimension)

**ParserDefinitionData**
- `parser_name`: name of the parser
- `data_format`: file format enum
- `platforms`: list of platform short names
- `metrics_to_skip`: list of metrics to skip
- `available_metrics`: optional list of available metrics
- `on_metric_check_failed`: action to take on metric check failure
- `titles_to_skip`: list of titles to skip
- `areas`: list of parsing areas (NonCounterGeneric)
- `metric_aliases`: list of metric alias tuples
- `dimension_aliases`: list of dimension alias tuples
- `kind`: parser kind (e.g., "non_counter.generic")
- `heuristics`: parsing heuristics configuration

**ReportTypeData**
- `pk`: report type ID in Brain (optional)
- `short_name`: short name for the report type
- `name`: full name of the report type
- `platforms`: list of platform IDs
- `dimensions`: list of dimension IDs
- `uses_titles`: boolean
- `uses_items`: boolean
- `metrics`: list of MetricInterestGroup (metric ID, interest_group)

## FlowWorkers

**DataDescriptionWorker**
- **Inputs**: `FileData`, `UserInfoData`
- **Outputs**: `DataDescriptionData`
- **Description**: Analyzes uploaded file and user comments to generate data description including metrics, dimensions, and metadata.

**TranslationWorker**
- **Inputs**: `DataDescriptionData`
- **Outputs**: `TranslationData`
- **Description**: Generates translations for metrics and dimensions when data is not in English.

**GitlabWorker**
- **Inputs**: `UserInfoData`
- **Outputs**: `PlatformData`, `FileData`, `UserInfoData`
- **Description**: Fetches GitLab issue, extracts platform information, downloads attached files, and updates user info.

**ParsingRulesWorker**
- **Inputs**: `DataDescriptionData`, `PlatformData`, `FileData`, `UserInfoData`, `ReportTypeData`
- **Outputs**: `ParserDefinitionData`, `ParsedData`
- **Description**: Generates parsing rules using AI agents and validates them. Supports streaming progress updates. Creates or updates parser definitions in Brain API.
